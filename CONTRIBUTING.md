# Contributing

Build and test the shared core with `./gradlew :common:build`. The full lane
matrix (every Forge version, build commands, toolchains), coding conventions,
CI setup, and branch-protection rules live in [AGENTS.md](AGENTS.md) — read it
before touching build code or adding a lane. Open a pull request against
`main`; the required checks listed in AGENTS.md must pass before merge.
